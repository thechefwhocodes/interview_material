# LLM Evaluation

- Application answer's correctly
- Use the right context
- Call the right tools
- Complete the task under realistic conditions

This can be done by

- Code checks
- LLM-as-a-Judge
- Human Review
- Production Sampling

LLM Eval vs Agent Eval

- Evaluate prompt, retrieval, response, tool and workflows vs Evaluate tool calls, multi-step decisions, task completion
- Code check, LLM-as-a-Judge, human review, production sampling vs Traces, span, session eval

Metrics to measure

- Correctness
- Relevance
- Groundedness
- Safety
- Latency
- Cost
